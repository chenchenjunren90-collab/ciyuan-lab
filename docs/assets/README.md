# 架构图资源

`architecture-v0.3.svg` 是可编辑的总体架构源图；`architecture-v0.3.png` 是其导出图，供根目录 `README.md` 和 `docs/architecture.md` 引用。修改源图后必须重新导出 PNG，并检查文字边界；保留现有文件名，架构含义变更同步更新架构文档与 ADR。

源图按 2026-09-05 的实现边界表述：

- 学情规划、课程辅导、质量监督由 FastAPI 本地编排，共享讯飞 MaaS 推理适配器。
- 课程证据检索支持可选 MaaS 重排；重排失败时保留原始召回排序。
- TokenHash 是确定性词元哈希表示，不是语义模型；不能把向量存储等同于语义检索能力。
- 学生学习页面已实现；教师看板与多用户权限仍待建设。
- 当前财经目录使用固定合成案例，不调用驼灵 API；项目材料留痕不自动计入掌握度。
- 画像依赖客观判定结果；离线回归不能替代真实模型、隔离运行环境和真人使用验收。

图中的实线表示服务连接，虚线表示反馈或使用边界；连接本身不代表外部服务已完成实测验收。
