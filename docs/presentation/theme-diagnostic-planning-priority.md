# 主题联动、诊断均衡与学习倾向优先

## 一、作品阐述

本次迭代提升个性化学习平台的可信度与一致性：用户选择的明暗模式和主色调覆盖完整学习流程；摸底测试不再出现正确选项位置高度集中；课程规划智能体优先尊重用户明确填写的学习起点，尤其避免零基础学生因猜题而被错误跳级。

## 二、功能思路

- 设置页切换主色或明暗模式后，摸底、规划、沉浸课堂、交流区、代码练习和弹窗同步变化。
- 诊断题保持服务端判分，但展示时确定性重排并重新标注 A/B/C/D，使正确位置均衡分布。
- 学习经历、目标与偏好决定课程主方向；短测用于发现知识断层和细调，而不是单独决定难度。

## 三、技术方案

- 使用全局 CSS 主题变量与高特异性语义规则统一覆盖课堂旧样式，并补齐夜间模式的内部卡片、输入框与代码任务界面。
- 后端诊断服务依据固定均衡序列重排选项；原课程包答案不改动、不下发，提交时按同一映射完成服务端判分。
- `self_profile_level` 进入下一课接口与 OpenAPI 契约。规划器收到 `newcomer` 时固定从 Python 运行环境、输入输出等基础节点开始，测评只参与后续调整。

## 四、运行效果

- 浏览器实测从深蓝夜间切换到青绿日间后，题号、按钮渐变、边框和主要卡片同步变化，再切回原设置正常。
- Python 初始诊断 12 题的正确选项覆盖 A、B、C、D 四个位置，单一位置不超过 3 题。
- 新增测试证明：即使测评画像包含列表、字典等高分证据，只要用户明确为零基础，下一课仍从 `PY-BASE-01` 与 `PY-BASE-02` 开始。
- 前端测试、构建、后端完整测试与仓库契约校验通过。

## 五、迭代计划

- 用真实初学者试用数据评估自述、短测和后续代码证据的动态权重。
- 将“学习倾向优先”扩展到 C 语言和数据结构课程。
- 增加主题对比度的自动化视觉回归截图。

## 六、创新之处

- 将“学习者主动表达的起点”作为课程规划智能体的正式决策输入，而非仅作为展示文案。
- 把短测定位为低权重、可解释的辅助证据，降低选择题猜测造成的错误分层。
- 主题系统覆盖沉浸课堂与代码学习场景，兼顾个性化审美、专注体验和无障碍阅读。
