# MVP v0.3 完整替代交付说明

## 一、作品阐述

本次交付将“词元研究所”从基础仓库升级为可部署、可演示、可验证的三课程助学平台。
平台面向计算机专业学生，以 C语言、Python、数据结构为首期范围，完整覆盖测评、规划、
结构化学习、RAG辅导、代码练习、画像更新和课后综合项目。

## 二、功能思路

系统由学情规划、课程辅导、质量监督三个逻辑智能体协同。Python承担完整闭环样板；
C语言和数据结构复用相同课程包契约与公共流程。财经元素只进入完成课程学习后的合成
综合项目，不改变计算机课程目标。模型负责规划、解释和受控编排，代码正确性由编译器、
隐藏测试和隔离执行环境确定。

## 三、技术方案

- Vue 3、TypeScript、Vite 构建红白代码学习工作台；
- FastAPI 模块化单体承载课程、RAG、画像、练习和智能体编排；
- PostgreSQL、pgvector、Redis 保存证据并支持课程隔离检索；
- 讯飞 MaaS 托管 DeepSeek-V4-Flash-0731 经统一模型适配层调用；
- Docker 无网络沙箱运行 C/Python 代码；
- 课程包 YAML、OpenAPI 契约和审核清单共同保证三门课程可融合扩展；
- Nginx 与 Docker Compose 提供可复现的生产演示部署。

## 四、运行效果

当前共有122个知识点：C语言42个、Python40个、数据结构40个。后端190项测试通过，
前端类型检查、3项交互单测和生产构建通过，75问RAG词法及pgvector评测关键指标均为
100%。生产环境真实 MaaS 调用显示课程辅导未降级、规划结果位于合法活动白名单、
综合项目生成来源为 `xfyun-maas` 且 `degraded=false`。三课程HTTP冒烟和真实Docker
代码执行均已通过。

## 五、迭代计划

后续重点是多轮对话上下文、更多自适应题型、真实学生试用、项目自动测试、教师证据摘要
和正式监控，不在当前PR中把这些规划描述为已实现功能。

## 六、创新之处

项目以“模型解释、确定性验证、证据可追溯”为主线，避免用语言模型主观判断代码；
通过统一课程包把知识、来源、题目、隐藏测试和综合项目纳入版本控制；用固定教学骨架
解决纯AI教材跳跃问题，再利用真实学习证据调整路径与题目；同时结合首经贸经管特色，
但只在课后应用环节使用公开结构和合成数据，保持计算机专业助学主线。
