# 受控个性化财经综合项目生成作品说明

## 一、作品阐述

本功能面向完成 Python 或数据结构基础学习后的计算机专业学生，把公开财经问题中的字段
结构和任务形态改编为综合编程练习。财经场景只承担应用载体作用，评价核心仍是文件解析、
字典与图结构、算法、异常处理、测试和结果可追溯性，不提供真实金融决策或财经问答。

## 二、功能思路

学生选择经过审核的课程项目模板并填写学习目标。系统结合模板允许的知识点、难度和预计
用时生成个性化任务说明，同时附上来源、计算机知识目标、限制条件和固定合成数据。外部
模型不可用或输出不符合要求时，页面自动显示固定安全版本，学生仍可继续完成同一练习。

## 三、技术方案

- 使用 UCI Bank Marketing、UCI Default of Credit Card Clients、CFPB 结构化字段说明和
  IBM AMLSim 作为问题结构依据，并在课程包中登记来源和许可；
- 本地按固定规则生成虚构记录，返回文件名、字段、数据行和 SHA-256，保证演示可复现；
- 通过讯飞星辰 MaaS 的 OpenAI 兼容接口调用 DeepSeek-V4-Flash-0731，按已审核模板组织场景；
- 模型只接收非身份化学习目标、知识点 ID 和已审核模板，响应必须通过严格 JSON Schema、
  来源白名单和敏感内容检查；
- 学习目标在进入模型前拒绝手机号、邮箱、身份证号、学号和凭据值；无模型时也会按目标、
  薄弱知识点、难度和预计用时生成确定性的个性化任务约束；
- 后端提供 `POST /api/v1/courses/{course_id}/scenario-projects/generate`，前端以统一接口展示，
  不为不同课程复制页面或智能体。

## 四、运行效果

本地已提供信用还款质量审计、银行营销活动统计、金融投诉分类统计和合成交易网络路径分析
四类项目。未配置外部模型凭据时，系统能够返回固定项目、合成数据、来源引用和安全提示。
HTTP 冒烟已跑通三门课程 122 个知识点、测评、路径、RAG 引用、分层提示、项目生成与证据
提交；全仓校验结果为 187 项后端测试通过，前端类型检查、组件测试和生产构建通过。

## 五、迭代计划

1. 使用项目专用环境变量完成一次真实讯飞 MaaS 最小调用和故障降级回归；
2. 补充基础、进阶和拓展三档学生需求的生成质量案例；
3. 增加合成数据下载、生成历史和教师证据摘要；
4. 邀请计算机专业学生试用，记录任务完成率、耗时和结构化反馈；
5. 正式发布前由课程教师复核知识目标、项目难度和业务表述。

## 六、创新之处

1. 不是让模型自由编题，而是在课程模板、知识目标和来源白名单内受控改编；
2. 公开资料只提供真实问题结构，学生使用的是带哈希的固定合成数据，兼顾现实感与隐私；
3. 模型负责组织任务，程序测试负责判断代码，避免语言模型主观替代正确性验证；
4. 断网或模型异常时自动回退到同知识目标的固定项目，保证竞赛演示稳定；
5. 将首经贸经管特色放在课后迁移实践层，不改变计算机专业课程助学的中心。
