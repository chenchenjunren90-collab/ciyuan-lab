# 红白代码学习交互界面作品说明

## 一、作品阐述

本轮将学生端从通用紫色后台风格升级为面向计算机专业学习的红、白、深灰代码实验室。
界面围绕“看课程状态—定位薄弱点—进入学习活动—代码验证—查看反馈”组织信息，服务
C语言、Python和数据结构同一套学习闭环。

## 二、功能思路

左侧固定课程与进度，顶部展示课程会话和系统能力状态，四个工作区分别承担概览、路径、
AI辅导和练习。知识地图支持按名称或ID即时搜索；练习工坊支持全部、编程、Debug和项目
筛选；关键卡片具有悬停、选中、加载、成功、失败及键盘焦点反馈。

## 三、技术方案

- 保持 Vue 3、TypeScript 和既有 HTTP API，不增加前端框架或公共接口；
- 使用统一红色设计令牌、深色代码侧栏、白色内容卡和微弱网格背景形成专业识别；
- 使用 CSS Grid、响应式断点和 `prefers-reduced-motion` 支持桌面及移动端；
- 掌握度环、进度条、智能体活动脉冲、卡片过渡和结果入场动画均由轻量 CSS 完成；
- 搜索和筛选使用 Vue 计算属性即时更新，不产生额外后端请求。

## 四、运行效果

桌面 1600×900 和移动 390×844 均无横向溢出；三门课程切换、四个工作区、知识点搜索、
空搜索反馈、练习筛选、项目生成、合成数据展示和代码编辑器均通过真实浏览器交互检查。
前端 TypeScript 类型检查、Vitest 和 Vite 生产构建通过。

## 五、迭代计划

1. 增加正式产品图标与品牌规范，并统一竞赛PPT视觉；
2. 补充学习日历、连续学习反馈和阶段成就，但不引入排名或无关社交功能；
3. 增加代码编辑器行号、语法高亮和可访问的错误定位；
4. 邀请真实学生完成可用性测试，依据任务时间和误操作记录继续调整。

## 六、创新之处

1. 视觉语言直接借鉴代码终端、验证状态和知识节点，而不是普通管理后台；
2. 多智能体以可观察的流程轨迹展示，不拆成三个重复聊天窗口；
3. 将学习证据、代码验证和来源状态放在首屏，强调可信学习而非模型噱头；
4. 同一响应式界面承载三门课程和财经综合项目，没有复制课程专用页面。
