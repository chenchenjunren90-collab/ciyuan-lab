# 课堂定义回答修正记录

## 现象与原因

提问“边界控制是什么”时，部分回答退回 range 公式或 async for 语法摘录，并附加不相关的固定问题。线上响应追踪显示，生成回答未引用补充资料时触发 `missing_supplement_citation`，原降级分支随后把资料摘录作为回答发布。另外，覆盖检查改写的检索词可能丢失原问题中的“边界”，导致文档选择偏移。

## 修改

- 联网检索保留学生原问题，覆盖检查的关键词仅作扩展；“边界控制”优先检索流程控制和内置类型中的起止值规则。
- 传给课程辅导的证据包含来源类型与标题，提示中明确可引用的联网片段。
- 当本地只有课程目标且生成结果漏引联网正文时，一次重答只提供联网正文；再次失败不发布公式拼接的假性解释。
- 定义问题先解释当前语境中的含义，再给对应例子。教师普通降级提示仍保留上下文续讲所需的示例线索，去掉原来不相关的“哪些操作改变了值”结尾。
- 质量审核逐项核对具体参数、预期输出及参数变更后的结论；允许根据证据规则推导新例子，但拒绝与规则矛盾的数字结论。
