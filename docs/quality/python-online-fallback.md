# Python 官方文档联网兜底

## 一、作品阐述

课堂五种角色优先使用本地课程知识库。当学生提出明确的 Python 语法问题且本地 RAG 没有证据时，系统有限度地读取 Python 3.11 中文官方文档，再由原有课程辅导与质量监督链生成回答。非 Python 问题不会触发联网。

## 二、功能思路

回答链依次执行：输入安全与课程隔离、原问题本地检索、有界上下文检索、Python 信号判断、官方文档联网检索、角色化回答、大模型语义审核、确定性发布门禁。任何环节失败均返回受控提示，不用模型常识冒充检索结果。

## 三、技术方案

- 固定白名单：`https://docs.python.org/zh-cn/3.11/`；
- 本地依据关键词选择官方页面，单次最多读取两页，不调用任意搜索引擎、不跟随外部链接；
- HTML 只提取正文段落、定义和代码块，并按问题词项重新排序；
- 联网证据使用 `WEB-PYDOC-*` 来源 ID，响应附带来源类型、标题和官方网址；
- 讯飞 MaaS 负责角色化组织与语义监督，规则负责引用真实性、相关性、长度、角色行为和敏感信息检查。

## 四、运行效果

`match case` 等本地知识库未覆盖的问题能够优先命中 Python 语言参考，而不是误命中 `re.match`；课程内已有的 `print`、列表、字典等问题仍使用本地 `SRC-PY-*` 证据。明确的股票新闻、其他编程语言和规则覆盖请求保持拒答。

## 五、迭代计划

后续根据真实提问日志扩充官方文档页面目录和中文同义词，增加联网命中率、延迟与失败率监控；只有评测证明必要时，才引入带 API 凭据的通用搜索服务。

## 六、创新之处

联网不是模型自由浏览，而是本地知识缺口触发的最小权限检索。页面域名、版本、数量、正文抽取、引用和最终发布均可审核，在扩大知识覆盖的同时维持课程边界和教学稳定性。
