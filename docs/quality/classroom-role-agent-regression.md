# 沉浸课堂角色智能体输入输出回归

更新日期：2026-08-31

## 测试对象与边界

课堂中的林老师、助教小程、小禾、阿拓和宁宁是课程辅导智能体的五种受控呈现角色，
不是五个可以自行修改画像或判题结果的自治智能体。它们共用课程 RAG 和质量监督链路，
但拥有不同的表达约束。学情规划、课程辅导和质量监督仍是职责独立的后台智能体。

本轮对五个课堂角色重复测试以下输入类型：

- 当前课题内问题：`for`、`if`；
- 当前课题外但仍属于 Python 的问题：`print`、字典、函数；
- 指代式追问：有最近对话、没有最近对话两种情况；
- 动态课堂问题：`return` 与 `print`；
- 越界问题：C 语言、数学问题；
- 规则覆盖与密钥索取；
- 模型结构异常、Markdown JSON 围栏、伪引用和异常审核字段。

## 修复前基线

在旧版公网接口共执行 27 次真实请求，得到以下问题：

1. 五个角色询问 `print` 全部答成列表遍历或 `for/if`；教师同题复测 4 次，4 次均错误。
2. 所有动态课堂一旦模型降级，都会落到列表课固定话术。
3. 质量监督输入没有学生原问题，因此无法判断“回答是否真正答题”。
4. 模糊追问没有历史却会猜测具体错误；总结角色会编造不存在的讨论。
5. 固定课堂主题被提前拼入查询，越界问题也可能获得不相关 Python 引用。
6. 最终使用降级回答时，执行轨迹仍可能显示课程辅导已正常完成。
7. 模型返回完整 Markdown fenced JSON 时会被误判为格式失败；异常 `reason_code`
   还可能触发未捕获类型错误。

原测试只验证角色名、引用存在和轨迹组件，没有验证回答是否回应了问题，因此没有发现这些缺陷。

## 修复后的处理链

```text
学生本轮问题
  → 输入安全与课程隔离（只检查原问题）
  → 本节 / Python 课程延伸 / 其他课程 / 无法判断四级边界判定
  → 原问题直接检索
  → 仅当“指代式问题 + 有最近对话”时做上下文检索
  → 课程辅导智能体按角色生成结构化回答
  → 质量监督同时读取原问题、角色、阶段、回答和引用
  → 本地引用 / 相关性 / 角色 / 长度 / 安全门禁
  → 放行；或改用问题相关的证据提取式回答；或明确拒答
```

关键改动：

- 查询不再预先拼接固定列表/字典主题；学生原问题拥有最高优先级。
- 本节外但仍属于 Python 的问题可以简要回答，同时返回所属知识点、学习阶段和后续计划建议；
  回答不会推进或改变当前课堂进度。其他课程仍被直接隔离，资料不足时不凭模型印象作答。
- 边界标签由知识点、语法符号和课程结构的确定性规则产生，模型只能在该边界内组织语言，
  不能自行宣称某个问题“在本节范围内”。
- `print` 等代码标识符及“字典、函数、队列”等中文技术词可作为独立检索变体，
  同时保留完整问句排序，避免宽泛技术词把更相关资料挤出结果。
- 最近对话最多 8 条、每条最多 500 字；没有历史时不允许角色假装知道“刚才”。
- 动态课的阶段描述来自真实知识点，不再套用列表课描述。
- 降级回答从实际命中证据提取最相关句子，再分别转换成教师、助教和三类同伴表达；
  不再按“列表/字典”写死事实。
- 教师必须小步解释并留下确认问题；谨慎同学必须提出共同思考问题；Debug 同学必须给出
  可执行实验；总结同学必须体现总结行为且不能虚构历史。
- 模型 JSON 解析只接受完整纯 JSON 或完整 `json`/无标签 Markdown 围栏；拒绝前后说明、
  重复键、非有限数、伪引用、异常字段类型和超量引用。
- 监督模型的格式异常不再把可能的“拒绝”反转为批准；候选回答不能绕过发布门禁。
- 执行轨迹记录直接检索、上下文检索、模型降级、证据替代和真实拦截原因。

## 自动验收

后端角色矩阵：

```powershell
.\.venv\Scripts\python.exe -m pytest apps/api/tests/test_classroom_role_matrix.py -q
```

五角色黑盒重复测试：

```powershell
.\.venv\Scripts\python.exe scripts/audit_classroom_roles.py `
  --base-url http://127.0.0.1:8000 --profile full --repeat 2
```

部署后将 `--base-url` 改为公网地址即可复用同一矩阵。脚本不读取也不发送模型密钥，
只使用合成学生编号。

本轮已验证：

- 五角色 `print` 修复后连续两轮 10/10 通过；
- 五种角色对本节外 Python 问题均能显示边界提醒；并覆盖 `print`、`try/except`、
  `def/return`、文件、类、元组、lambda、import、yield、排序、JSON 和异常处理等跨阶段语法；
- MaaS 网络不可用时仍能稳定返回与问题相关、带真实引用、角色可区分的保守回答；
- 越界问题、提示注入、无历史模糊追问均不会再得到列表课固定话术；
- fenced JSON 拒绝不会被反转放行，异常审核字段不会产生 500；
- 前端最近对话字段、类型检查、9 项前端测试及生产构建通过。

## 当前保留边界

- 最近对话由当前页面按用户传入，尚未做服务端持久会话；关闭页面后的长期记忆依赖学习画像，
  不依赖聊天文本。
- 课堂角色不能修改能力分数，代码结果仍只由确定性验证器判定。
- 模型可用时使用模型语义审核；模型不可用时只发布经过引用、相关性、角色和安全规则验证的
  证据提取式回答，并在轨迹中明确标记降级。
