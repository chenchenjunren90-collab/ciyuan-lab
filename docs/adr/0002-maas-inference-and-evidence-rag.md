# ADR 0002：统一 MaaS 推理与课程证据检索

- 状态：接受；代码实现完成，真实环境验收另行记录
- 日期：2026-09-05
- 背景：依据用户确认的产品路线，学科能力通过受控知识、检索、教学流程和确定性验证建立。

## 决策

三门课程及三个逻辑智能体共用模型适配器和推理并发限制。课程问答与课堂检索可按配置增加讯飞 MaaS 文档重排，供应商只对已有证据排序；来源、正文和引用由应用持有，失败返回原始候选并明确降级。

保持 FastAPI 模块化单体、本地流程编排和 PostgreSQL 业务数据；不增加微服务，不把三个本地逻辑智能体描述为已发布的星辰 Agent 应用。财经扩展继续使用登记的合成场景。

当前384维 TokenHash 索引保留为可复现的词项向量实现。未来语义 Embedding 接入需要单独核对服务维度、记录模型与知识版本、重建索引并验证效果，不能混用旧向量。

## 结果与验收

专用训练运行分支与数据工具已移除；MaaS 重排默认关闭，避免把接入代码误认为实际开通。模型审核失败不能放行生成草稿，基础设施故障不能转化为学生成绩。

本次不进行线上部署、历史数据修复或真实模型调用。静态与业务回归结果、真实环境验收缺口见 [审查报告](../audits/backend-competition-maas-review-20260905.md)；配置见 [服务接入说明](../provider-integration.md)。架构图以SVG源码为准，并同步导出PNG。
