# 开源项目借鉴与许可证台账

> 记录日期：2026-08-26。该台账用于技术调研与合规说明。除仓库依赖清单已明确引入的第三方包外，
> 下列项目均未复制源代码；目前仅借鉴公开架构思想，并由本项目独立实现。

| 项目 | 许可证/状态 | 借鉴的思想 | 本项目处理方式 |
| --- | --- | --- | --- |
| [Judge0](https://github.com/judge0/judge0) | GPL-3.0 | 不可信代码需要独立执行环境，并限制时间、内存、输出与网络 | 未引入其代码或服务；本地用自研适配器调用一次性 Docker 沙箱 |
| [DMOJ judge-server](https://github.com/DMOJ/judge-server) | AGPL-3.0 | 判题器与业务服务解耦；测试用例、运行时和结果比较分别负责 | 未引入其代码；只作为后续扩展独立判题节点的架构参考 |
| [online-judge-tools/template-generator](https://github.com/online-judge-tools/template-generator) | MIT | 由受控模板与种子生成题面、启动代码和随机测试，而不是让模型自由生成答案 | 独立实现四类 Python 确定性模板；题目 ID 与学生会话及轮次绑定 |
| [AlgoForge](https://github.com/ninjawerk/algoforge) | 检查时仓库页面未显示明确许可证 | 学生侧公开题面与服务器侧隐藏测试物理分离；内容库设置自动校验门禁 | 仅记录设计观察，不复制代码；本项目公共响应禁止出现隐藏测试和参考答案 |

## 合规规则

1. 引用一个新项目之前，必须记录仓库地址、许可证、用途和是否复制代码。
2. 无许可证、来源不明或许可证义务无法满足的项目，只允许观察产品与架构，不复制任何代码或内容。
3. 学习题、课程讲解和测试用例由项目组原创或从允许使用的事实资料重新设计，禁止搬运刷题网站题面。
4. 如未来实际引入 GPL/AGPL 组件，须先由负责人评估分发、网络服务和源码公开义务；未完成评估不得合并。
5. PPT 中使用“借鉴”时必须准确表述为设计参考，不能把第三方成果包装为项目自研成果。
