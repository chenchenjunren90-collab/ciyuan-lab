## 六项复核

1. **首课编排**：基线已修复。`generateLearningPlan` 调用 `nextClassroomSession`，
   通过 `ClassroomPlanPreview` 展示实际课程，而不是把教学对话的依据不足状态当作学习计划。
   编排失败保留测评，给出可重试提示，不伪装成已生成。
2. **讲解为空**：基线已修复。`LessonBeatContent` 展示解释、关键点、代码与步骤；
   PY-BASE-05 / PY-BASE-07 的 API 回归覆盖示例和具体复盘。
   本次新增组件渲染回归，覆盖完整示例、逐步讲解和复盘。
3. **回答模板化**：本次补强模型不可用时的证据提取路径。比较/嵌套问题优先选择
   对应意图的证据，保留分号连接的必要解释，并给事实保留更大的角色字数预算。
   自编 BASE 教学提要升至版本 3，补充 elif/else if 区别和嵌套条件规则。
   五角色均覆盖这两个具体问题，缺少代码的排错请求要求补充信息而不猜测。
   此修改不是任意问题的语义理解保证，亦不代表生产 MaaS 实测通过。
4. **规划与课堂不一致**：基线已增加“后续目标 / 本节先学习 / 前置”因果说明；
   现有前置断层 API 测试通过，本次也覆盖实际计划标题与规划理由的组件渲染。
5. **摸底题号跳跃**：基线已有跨知识点抽样说明，明确未抽到不等于已掌握。
6. **落地页 CTA**：基线已使用原生 `form @submit.prevent` 与 `button type="submit"`，
   设备选择等其他按钮均为 `type="button"`。本次保留，未做真实浏览器、屏幕阅读器或
   原 `click @ref` 工具的端到端复测，不能把代码语义检查等同于其兼容性实测。
