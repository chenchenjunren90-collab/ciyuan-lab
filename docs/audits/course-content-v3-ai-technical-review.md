- 复核阶段进一步修正 C `argc` 的标准边界，并补齐“集合与映射抽象”中的集合语义。

## 依据与核查方法

- C 语言边界以 WG14 公布的 C11 草案 N1570 和项目 C17 教学子集为依据：
  https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf
- Python 行为以 Python 3.11 官方教程、语言参考和标准库文档为依据：
  https://docs.python.org/3.11/
- 算法条目按输入规模、数据结构不变量、适用前提、最坏/平均复杂度分别核对；
- 客观题逐条检查唯一 `accepted_answers`，正确项与错误项不依赖模型评分；
- C 文本文件题的等价参考实现使用 `gcc:13.4.0-bookworm`，以
  `-std=c17 -Wall -Wextra -Werror` 编译，正常、空文件、文件不存在 3 条路径全部通过。

## 仍然保留的边界

- AI 技术复核不是教师正式审核，不能据此宣称正式教学发布；
- 现有 RAG 仍只索引 `reviewed` 且 `rag.eligible: true` 的项目原创来源，不会把 122 个草稿知识点
  自动写入正式索引；
- 代码片段与算法轨迹不全部是独立完整程序，只有声称可执行的确定性任务才必须通过编译或测试；
- 外部官方文档仍为 `reference_only`，未复制进知识库，避免扩大授权范围。
