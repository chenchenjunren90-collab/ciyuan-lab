# MVP v0.2 发布候选验收记录

验收日期：2026-08-25

## 已完成范围

- C 语言、Python、数据结构各 40 个知识点，共 120 个；三门课程使用同一课程包契约。
- 120 个知识卡均具备摘要、关键要点、示例、常见误区、练习映射和来源引用。
- 知识内容仍保持 `draft`，等待教师逐条审核；系统没有自动伪造 `reviewed` 状态。
- RAG 入库清单共 133 个候选：13 个已审核来源片段可入库，120 个知识点因待人工审核被拦截。
- 默认内存检索可离线演示，可选 PostgreSQL/pgvector 混合检索；两条路径均按课程隔离。
- 学生端已覆盖能力基线、路径推荐、知识卡、带引用辅导、三级提示、练习验证、
  财经背景综合项目和项目人工评审入口。
- 讯飞支持 HTTP APIPassword 或 APIKey/APISecret；驼灵仅限授权脱敏课后项目，均有安全降级。

## 尚未冒充完成的事项

1. 课程知识点需要指导教师或课程教师逐条复核后，才能改为 `reviewed` 并进入正式 RAG 索引。
2. 当前机器未配置讯飞和驼灵真实凭据，因此外部实网联调待授权和额度就绪后执行；
   目前已完成协议适配、Mock 测试、失败降级和配置自检。
3. 75 问基线显示跨课程问题拒答率仍为 73.33%（内存）和 80%（pgvector）；虽然不会返回
   其他课程来源，但仍需继续提高问题域判定，不能把“命中当前课程相似片段”直接等同于可回答。
4. 初步版本不含统一身份认证、教师评分后台、生产监控和大规模并发能力。

## 发布判断

该版本满足“初步版本可演示、主流程可运行、来源可追溯、结果可验证、失败可降级”的目标，
适合作为指导老师审阅和团队继续填充内容的技术基线；不适合作为未经教师审核的正式教学产品发布。
