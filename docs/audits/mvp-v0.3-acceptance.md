## 本轮质量修复

1. 修复中文检索把连续文本错误拆为单字的问题，消除无关字符碰撞；
2. 复合问题同时检索完整问题与最多四个分句，每个证据片段保留最高相关分；
3. 对明确点名其他课程专属术语的问题执行透明课程域门禁；
4. pgvector 全文检索改用已转义词项 OR 查询，避免所有词项被错误要求同时出现；
5. 将不存在的“项目人工评审”改为可验证的项目证据完整性检查；
6. 将 HTTP 冒烟从单门 Python 扩展为三门课程，并增加真实 Docker 代码执行模式。
7. 将个性化财经项目生成纳入 HTTP 冒烟，并验证无凭据时的固定安全降级。
8. 选择性吸收前端协作者 PR 的请求超时与异常测试思路，并从 C 语言目录 PR 中提取
   编译链、随机文件访问、带标签联合和模块可读性增量；未合并重复课程 ID、空测评或
   不可核验来源。
9. 修复演示准备脚本忽略 `npm ci` 失败仍报告成功的问题；前端改为由启动脚本直接持有
   Vite 进程，并增加端口占用、API 与页面就绪检查，避免遗留孤立进程。
10. 用服务器诊断替代学生自报“会/不会”，初测与重测使用不同题集，前端不接收答案键。
11. 新增四类原创 Python 确定性变式题；题目 ID 绑定学生会话和轮次，公开题面与隐藏测试分离。
12. 为重点 Python 知识点增加“学习顺序—分步例题—立即检验”，避免把自由生成文本当教材。
13. 修复切换课程后仍停留在旧课程功能标签、导致新课程诊断不可见的前端状态问题。

## 仍需外部条件的事项

1. 讯飞 MaaS 仍依赖项目额度与服务可用性；真实密钥只保存在服务器权限受限的环境文件，
   不进入 Git、日志或前端；
2. 122个知识点目前是项目初步内容，不应作为已经课程教师确认的正式教材发布；
3. 当前版本不含统一身份认证、教师后台、生产监控和大规模并发能力；
4. 离线 `TokenHashEmbedder` 只用于打通可复现工程链路，不宣称等同于正式语义向量模型。

这些边界不影响竞赛初步版本的线上或本地演示，但在对外介绍时必须如实说明。
