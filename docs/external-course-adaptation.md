## 原文核对后做的教学修正

网道不是语言标准。其固定版本有部分不严谨或错误表述，本平台没有直接批量抓取全文：

1. 指针不是整数类型；指针算术有数组边界限制，尾后指针不能解引用。
2. 全局变量不等于动态分配的对象，不能对普通全局变量调用 `free`。
3. C 允许 `char a[3]="cat"` 省略放不下的终止符，但此数组不能作为正常 C 字符串交给字符串函数。
4. 数组越界属于未定义行为，不保证“正常运行并改变相邻变量”。
5. 区分函数声明与定义：块内可以声明函数，但不支持标准 C 的嵌套函数定义。

复核参考：WG14 [N1570 公开委员会草案](https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf)，6.2.4（存储期）、6.2.5/6.3.2.3（指针类型与转换）、6.5.6（加减运算）、6.7.9p14（字符数组初始化）、6.9（外部定义）、7.22.3（动态内存）。它是 C11 委员会草案，不冒充 C17 正式标准；这里只用于核对上述基础规则，没有导入全文。

OpenDSA 的普通二分查找与平台的“最左命中”要求不同；讲义明确了这一改编。循环队列明确了本地 front/rear 的定义。图遍历补充邻接表示的复杂度前提。散列表补充整圈探测上限，防止满表情况下无限循环。
