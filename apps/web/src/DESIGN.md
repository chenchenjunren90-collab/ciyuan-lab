# 词元研究所界面

v0.10.0 采用「光刻终端」方案，可逐步检查二分查找的分支、边界与比较路径。浅色版使用淡灰页面、白色选中项和灰色内凹轨道，深色使用同一控件结构。标题使用 800 字重的思源宋体，正文与导航使用同一款自托管可变宋体。设置面板使用系统界面字体，代码使用等宽字体。颜色强调集中在路径细线、焦点和状态文字。

新用户默认使用极简白。主题开关在极简白和暮紫沉蓝间切换。旧版浅色偏好迁移到极简白，旧版暗色偏好迁移到暮紫沉蓝。减少动态、高对比和设备模式继续使用原来的个人设置。

工作台保留三门课、知识点导航、实验、依据展示与代码判题入口。移动端的路径图移到文字下方。代码和变量表达式采用等宽字体。高亮同时使用线宽、节点和文字表示。
