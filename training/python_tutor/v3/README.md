# Python 垂类辅导模型训练包 v3

V3 用于第二轮 MaaS 微调。第一轮 Qwen3-14B LoRA 的接口格式、引用和安全边界均通过，
但锁定评测仅通过 4/12，低于 DeepSeek 的 8/12。失败集中在概念解释、调试、同伴讨论和
课堂总结过短、证据覆盖不足，而不是接口连通或 JSON 格式问题。

## V3 改进

- 共 **1400** 条，保留 V2 的公开课程来源数据并增加真实运行提示对齐样本。
- 覆盖教师、助教、小禾、阿拓、宁宁五种课堂角色；新增 `peer_summary` 与
  `safety_refusal` 类别。
- 定向答案至少组织两项来源事实，再给可验证的下一步，降低泛化空话比例。
- 只读取 `course_packs/python/` 的公开概念、题面和提示；未读取或复制
  `training/python_tutor/v1/eval/golden.jsonl`。
- `candidates/ai-audit-report.json` 记录 `AI-AUDIT-V3` 的可复现性、格式、引用、角色、
  长度、测评边界与敏感信息检查。该标记不等同于教师人工签字。

上传文件：`approved/sharegpt-python-tutor-v3-approved.jsonl`

## MaaS 第二轮设置

- 基础模型：Qwen3-14B（与 V2 相同）
- 训练方式：SFT
- 训练方法：LoRA
- 测试占比：15%
- 学习率：`5e-6`
- 训练轮数：`2`
- Rank：`8`
- Alpha：`16`
- Dropout：`0.1`
- 其余序列长度、精度与批量参数保持平台稳定默认值

V2 在训练约 1.3 轮后 loss 已接近低位，继续到 3 轮没有换来锁定评测收益。V3 因此降低
学习率和训练轮数，以减少模板过拟合。训练完成后仍使用原有 12 题锁定集；必须同时满足：

1. JSON 格式、引用和安全边界 12/12；
2. 自动通过至少 9/12，并高于 DeepSeek 的 8/12；
3. 人工复核确认没有完整代码代写、隐藏测评泄露或角色错位；
4. 连续两次评测结论一致，再允许打开 Python LoRA 路由。

锁定评测不得上传到 MaaS 训练集。
